# Dana Zaben Portfolio

Personal portfolio for Dana Zaben, Computer Engineering student and aspiring Backend Developer.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Update content

Edit files in `src/data/` — you usually do not need to change UI components.

| What to add | File |
| --- | --- |
| Name, GitHub, LinkedIn, email | `src/data/profile.ts` |
| Projects | `src/data/projects.ts` |
| Skills | `src/data/skills.ts` |
| Certificates | `src/data/certificates.ts` |
| Volunteering | `src/data/activities.ts` |
| Education | `src/data/education.ts` |
| Portrait | Replace `src/assets/profile.jpg` |
